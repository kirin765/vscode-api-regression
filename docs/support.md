# Support and update terms

## Support

Report a problem with the repository issue tracker for this extension, or by email to the address on the Marketplace listing. Include:

- VS Code version and operating system
- The command you ran and the exact message shown
- The relevant lines from the **API Regression** output channel (API Regression: Validate Configuration writes there)

Never include real credentials, tokens or unredacted response bodies in a support request.

## What support covers

- Bugs in the advertised workflow (capture → rerun → review → export).
- Configuration validation errors.
- License activation problems on a supported platform.

Support does not cover: network or server issues on your APIs, unsupported request types, or custom certificate/proxy setups.

## Updates

- A license covers the **current major version** of API Regression.
- Minor and patch releases within that major version are provided at no additional cost.
- Continued use of the purchased version remains available.
- A future major version may require a separate purchase. Any such change will be stated on the Marketplace listing before release.
- This is a one-time license, not a subscription. It does not create recurring revenue for the publisher or recurring entitlements for the buyer.

## Refunds

Refunds follow the policy shown on the Marketplace listing at the time of purchase, subject to the payment provider's rules.

## Response times

Support is best-effort. No guaranteed response time is offered by this version.
